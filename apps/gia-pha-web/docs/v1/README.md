## What's in V1

This folder contains all documentation from the **first phase** of Heritage Cloud development — a single-tenant Vietnamese family lineage management system.

### Documents

| Folder | Contents |
|--------|----------|
| `prd/` | Product Requirement Documents (PRD-00 through PRD-06) |
| `implementation/` | Implementation Plans (IP-00 through IP-06), API design, tech architecture, roadmap |
| `db-design/` | Database schema design (PostgreSQL + Prisma) |
| `ui/` | Static HTML mockups for all screens |

### Features Delivered in V1

- ✅ Global Design System (imperial Vietnamese theme)
- ✅ Homepage with clan stats dashboard
- ✅ Lineage Visualization (Neural Root + Traditional Tree + Brain Node Graph)
- ✅ Digital Profile pages for family members
- ✅ Ancestral Map (grave site tracking with Google Maps)
- ✅ Ritual Calendar (lunar + solar calendar with memorial days)
- ✅ Family Duty Management (Kanban-style task board)
- ✅ Vercel + Supabase deployment
- ✅ Basic auth (NextAuth credentials provider)

### V1 Limitations (Addressed in V2)

- Single-tenant: one clan per deployment
- No public landing page for marketing
- No proper sign-up/registration flow for new users
- No multi-tenant data isolation
- No subscription/payment system (planned for future)
