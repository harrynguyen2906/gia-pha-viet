## LINE-101: Fix Bug Hiển Thị Đúng Theo Cấp Đời

**Mức ưu tiên:** P0 — Critical Bug Fix  
**Độ phức tạp:** Trung bình  
**Files:**
- `src/components/lineage/D3LineageTree.tsx` (sửa logic dựng cây, ~line 50–90)

### Phân Tích Root Cause

```typescript
// ❌ Logic hiện tại — SAI
const allParentIds = new Set(members.flatMap((m) => m.parentIds));
const roots = members.filter(
  (m) => !allParentIds.has(m.id) || m.parentIds.every((p) => !memberMap.has(p))
);
```

**Vấn đề:** Nếu member A (đời 5) có `parentIds: ["xyz"]` nhưng "xyz" không nằm trong `memberMap` (vì không được fetch hoặc limit=200), thì A pass condition `m.parentIds.every(p => !memberMap.has(p))` → bị coi là root → hiển thị ở level 1.

### Giải Pháp

```typescript
// ✅ Logic mới — dùng generation để xác định root
const minGeneration = Math.min(
  ...members.filter((m) => m.generation != null).map((m) => m.generation!)
);

const roots = members.filter((m) => {
  // Member có generation thấp nhất = root
  if (m.generation === minGeneration) return true;
  // Member không có parentId trong dataset VÀ generation == minGeneration
  return false;
});

// Với member "mồ côi" (parentId ngoài dataset, generation > minGeneration):
// → KHÔNG coi là root
// → Gắn vào virtual placeholder ở đúng depth, hoặc bỏ qua
```

**Bổ sung:** Sort children theo generation trước khi build hierarchy:
```typescript
root.sort((a, b) => (a.data.generation ?? 0) - (b.data.generation ?? 0));
```

### Acceptance Criteria

- [ ] Seed 5 đời → G1 trên, G5 dưới, không orphan sai level
- [ ] Member thiếu parent trong dataset, generation > 1 → không hiển thị ở level 1  
- [ ] Virtual root "Tổ Tiên" chỉ xuất hiện khi có >1 root thật sự (cùng generation)
- [ ] Không cycle / infinite recursion

```typescript
// ❌ Xóa
const linkPath = d3.linkVertical<...>().x(...).y(...);

// ✅ Thay bằng custom elbow path
function elbowPath(d: d3.HierarchyPointLink<MemberNode>): string {
  const sx = d.source.x; // parent x
  const sy = d.source.y + NODE_H / 2; // bottom of parent
  const tx = d.target.x; // child x
  const ty = d.target.y - NODE_H / 2; // top of child
  const midY = (sy + ty) / 2;
  return `M ${sx},${sy} V ${midY} H ${tx} V ${ty}`;
}

g.selectAll(".link")
  .data(links)
  .join("path")
  .attr("d", elbowPath)
  .attr("fill", "none")
  .attr("stroke", "rgba(197,160,89,0.35)")
  .attr("stroke-width", 1.5);
```

### Mini-Map Rendering Logic

```typescript
// Sau khi render cây chính, render mini-map
function renderMiniMap(
  nodes: TreeNode[],
  links: d3.HierarchyPointLink<MemberNode>[],
  viewBox: { minX, minY, totalW, totalH },
  currentTransform: d3.ZoomTransform
) {
  const miniSvg = d3.select(miniSvgRef.current);
  miniSvg.selectAll("*").remove();
  
  // Set viewBox to fit entire tree
  miniSvg.attr("viewBox", `${viewBox.minX} ${viewBox.minY} ${viewBox.totalW} ${viewBox.totalH}`);
  
  const mg = miniSvg.append("g");
  
  // Simplified links (thin lines)
  mg.selectAll("line")
    .data(links)
    .join("line")
    .attr("x1", (d) => d.source.x)
    .attr("y1", (d) => d.source.y)
    .attr("x2", (d) => d.target.x)
    .attr("y2", (d) => d.target.y)
    .attr("stroke", "rgba(197,160,89,0.2)")
    .attr("stroke-width", 0.5);
  
  // Simplified nodes (small rects)
  mg.selectAll("rect")
    .data(nodes.filter((n) => n.data.id !== "__root__"))
    .join("rect")
    .attr("x", (d) => d.x - 3)
    .attr("y", (d) => d.y - 2)
    .attr("width", 6)
    .attr("height", 4)
    .attr("fill", (d) => d.data.isDeceased ? "rgba(197,160,89,0.3)" : "rgba(197,160,89,0.6)");
  
  // Viewport rectangle
  // Tính toán visible area từ currentTransform + container dimensions
  const visibleX = (-currentTransform.x) / currentTransform.k;
  const visibleY = (-currentTransform.y) / currentTransform.k;
  const visibleW = dimensions.w / currentTransform.k;
  const visibleH = dimensions.h / currentTransform.k;
  
  mg.append("rect")
    .attr("class", "viewport-rect")
    .attr("x", visibleX)
    .attr("y", visibleY)
    .attr("width", visibleW)
    .attr("height", visibleH)
    .attr("fill", "rgba(138,0,0,0.15)")
    .attr("stroke", "#8a0000")
    .attr("stroke-width", 1.5);
}
```

### Click-to-Pan Interaction

```typescript
// Click trên mini-map → pan cây chính
miniSvg.on("click", function (event) {
  const [mx, my] = d3.pointer(event, mg.node());
  
  // Tính transform mới để center main view tại (mx, my)
```
