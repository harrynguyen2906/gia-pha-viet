## Task 4.1.4: Kanban Board — User Avatar Display

**ID:** `HUB-004`
**Output:** Enhanced `DutyKanbanClient.tsx` → `DutyCardDisplay` component

**Các bước chi tiết:**

1. **Tạo `UserAvatar` micro-component** (inline, hoặc `src/components/shared/UserAvatar.tsx`):

   ```tsx
   function UserAvatar({
     name,
     avatarUrl,
     size = "sm",
   }: {
     name: string;
     avatarUrl?: string | null;
     size?: "sm" | "md";
   }) {
     const dim = size === "sm" ? "w-6 h-6 text-[10px]" : "w-8 h-8 text-xs";
     const initials = name
       .split(" ")
       .map((w) => w[0])
       .join("")
       .slice(0, 2);
     return avatarUrl ? (
       <img
         src={avatarUrl}
         alt={name}
         className={`${dim} rounded-full object-cover border border-antique-gold/30`}
       />
     ) : (
       <div
         className={`${dim} rounded-full bg-imperial-crimson/20 text-parchment/70 font-header flex items-center justify-center border border-antique-gold/20`}
       >
         {initials}
       </div>
   ```
